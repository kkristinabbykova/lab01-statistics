## Как запустить

```bash
pip install -r requirements.txt
python -m pytest -q                      # все автотесты

# интерактивный датчик (marimo)
marimo edit ktvd/datchik.py              # редактировать
marimo run ktvd/datchik.py               # как приложение

# сайт: экспорт датчика в docs/datchik/ + лендинг docs/index.html
python tools/build_site.py
```

## Как добавить шрифты

1. На fonts.google.com добавь все нужные шрифты в подборку («Get font») и скачай **один раз** в конце
   («Download all»): каждое скачивание содержит всю подборку целиком.
2. Положи zip в одну папку, например `downloads/`.
3. Если семейства нет в `data/font_categories.csv`, допиши строку: категория по каталогу Google Fonts
   (`sans`, `serif`, `display`, `handwriting`, `mono`).
4. Пересобери всё:

```bash
python tools/unpack_fonts.py downloads/ fonts/          # разложить по категориям без повторов
python -m labfont.collect fonts/ data/fonts.csv         # измерить
python tools/build_fonts_nb.py                          # собрать ноутбук (числа в тексте из расчёта)
python tools/run_nb.py ktvd/fonts.ipynb                 # выполнить (или jupyter nbconvert --execute)
python tools/build_site.py                              # обновить сайт
```

Папку `fonts/` с самими шрифтами в репозиторий не кладём: она большая. Для воспроизводимости хватает
`data/fonts.csv` и одного образца для схемы (`data/fonts_sample/`, лицензия SIL OFL).

## Публикация сайта на GitHub Pages

Репозиторий → Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/docs`.
Чтобы ссылки на ноутбуки на сайте вели в репозиторий, собери лендинг так:

```bash
LAB_REPO_URL=https://github.com/<логин>/<репозиторий> python tools/build_site.py
```
